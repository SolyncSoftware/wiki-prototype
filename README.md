# Camellia Wiki

The site is being migrated from Jekyll to SvelteKit. The homepage and migrated
articles are served from `src/routes` and `src/articles`; public files are in
`static/assets`.

## Development

```sh
bun install
bun run dev
```

## Validation and build

```sh
bun run check
bun run lint
bun run build
bun run preview
```
